# Botanical asset gate

This source builds the later branch, cordate and fern studies. Run `src/make_atlases.py` before Blender construction. All derived leaf maps, vascular networks and panel arrays are regenerated, not shipped. The root README gives the source-derived quickstart.

The `patch` build additionally expects `assets/original_substrate.blend` and inherited mud maps. Those packed/scanned inputs are not in this public checkout. The native study scenes named in the historical notes are also not bundled; the three procedural build types generate new scenes when run.

`ARCHIVE-NOTES.md` is the original delivery description, with historical worker paths normalized. Its completed renders and portability claims refer to that earlier archive, not to a fresh execution of this repository. `evidence/` preserves historical camera plans and review findings. The final review did not approve whole-forest replication.

`src/validate_packed_delivery.py` is a historical delivery check requiring native outputs and the exact separately supplied original forest. Its old absolute default input was normalized to an `inputs/historical/` path. It is not a self-contained test for this checkout.
