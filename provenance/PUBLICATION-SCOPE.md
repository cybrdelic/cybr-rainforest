# Publication scope

This is an unpacked, source-only recovery from five project archives: the A01 working source, the later asset-gate rebuild source, the code-only integrated-repair recovery, the native recovery code-and-proof package, and the V14 specification. No new native scene or render was executed while preparing it.

Included: project Python source, original host requirements, selected historical technical/review records, botanical/source attribution, original recovery/pipeline stills, the existing branch MP4, and a GIF converted from that MP4.

Excluded: all native `.blend` models and packed assets; scanned mud textures; generated leaf PNG/NPY/NPZ assets; raw logs, transient process records and session-specific launchers. Numerical texture generators are retained, but packed substrate and full-forest inputs remain missing. Their omission must not be treated as a completed source recovery.

The historic worker-root prefix in retained text was normalized to `inputs/historical/`. Source defaults that used it are archival placeholders and require deliberate local configuration. The portable recovery entry point and EXR compatibility module did not need that normalization. The private account-storage/routing section was removed from the V14 historical delivery report. Old account-storage commentary was removed from the integrated-repair archive notes, and the obsolete release packager that hard-coded that account-storage status was excluded.

Original archive README files are retained as `ARCHIVE-NOTES.md`, with a prominent scope notice. Original evidence and recovery manifest hashes describe historical bytes; paths and text normalized for publication are not a claim of byte-identical historical files. Fresh published-content identity belongs to the Git commit.

No third-party license was removed or replaced, and no new license is assigned to the project. The inherited Poly Haven manifest is retained byte-for-byte. Its raw asset files are not redistributed here.
